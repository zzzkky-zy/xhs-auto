# 单张图片的视觉方案与生成提示词

所有模块以及漫画角色表都用这里的约束。先读模块和选中预设，再读 [Naturalizer](modules/naturalizer/guide.md) 的两个参考。只填写与本图有关的内容，生成前替换全部占位项。文字经 Humanizer 核对后固定，模型只呈现，不续写。

同时执行[对外文案禁用规则](../audience-copy.md)。研究来源、制作方式、示例性质和审查说明留在内部方案，不能误填为可见文字；清单和提示词都不得要求模型把它们画出来。

## 出图前留存的方案

```markdown
图号/文件：
本图角色：封面 / 内页 / 漫画页 / 角色参考表
用途、读者与核心信息：在哪看到，已知什么，看完需理解/能做什么
模块与已读资源：各维度的确定值与定义文件
本帖所选预设风格：完整定义文件、主参考、按原方法选择的理由；对照本批其他帖子未重复
同帖视觉约定：背景/主色/强调色与色值、线条/材质、字形层级、角色/物件
主体与场景：谁/什么、数量、位置、时间地点、动作及理由
构图：画幅，主视觉/文字/辅助区的位置与比例，留白和安全区
信息层级与阅读顺序：先看哪里、接着哪里、最后得到什么
关系清单：节点、分组、箭头起止与含义；漫画逐格动作和对白归属
光线、材质、尺度：光源与影子、材料表现、大小、接触、遮挡、透视
姿态与功能：支撑点、视线、手与道具、工具结构和用途
不适用项：如平面矢量不加投影，以色块/线宽稳定代替摄影光影
准确文字：标题、标签、对白、数字单位与真实条件，逐项原样列出；不含声明/解释/免责附注
具体避免项：如箭头不得反向、气泡尾不得指错人，不写笼统“减少AI味”
参考材料：实际路径或宿主附件标识、用途与需保留的特征；未传图注明仅文字提取
真人封面另记：face_reference 的用户来源/原件路径/核对哈希、本批准确副本及实际图1输入标识；封面之外不使用真人
本轮唯一目标：初稿或当前一个修正目标
```

## 给生成工具的自足提示词

将方案转成下列提示词，展开所选定义；模型看不到的文件，不能只写路径代替内容。删掉未选择的分支，不传入整套风格目录。

```text
制作一张[用途]，目标读者为[具体读者]，输出[尺寸/比例、语言]。
第一眼看见[主信息]，按[明确顺序]读到[支持信息]，理解[目标]。
主体为[数量、外观、动作]，位于[具体场景]。
画面分区：[主视觉/文字/辅助区相对位置与比例、留白、安全区]。
采用[完整画风/渲染描述]：[线条、色块/笔触、材质、深度、字形]。
颜色固定为[背景、主色、强调色及色值]；同色表示[统一语义]。
布局：[展开结构，不只写布局名]；关系：[准确起止、分组、先后或无因果]。
[漫画逐格写景别、人物位置、动作、对白顺序和气泡尾指向。]
实际约束：[适用的光源/阴影、透视、尺度、材质、接触、支撑、视线、功能]。
[平面/像素/水墨等说明有意抽象之处和仍须准确的关系。]
辅助元素仅保留[名称/位置]，作用是[具体信息作用]。
图中文字仅允许以下内容，按所列层级/位置原样排入，不改写、续写或添装饰词：
[逐行准确文字、数字、单位、真实限定与位置；无字图明确不出现文字。]
不得增加任何声明、解释或免责文案；页脚、小字、括号、气泡、贴纸、截图和水印位置同样禁止。不要说明制作来源、作者身份、经历归属、示例性质或使用责任。没有列入清单的文字一律不生成。
参考[实际传图标识]仅用于[指定的角色/颜色/材质/构图部分]。
[无传图时改成具体文字描述，不声称模型已看见图片。]
[真人封面必须实际传图1，按 gbro 原模板保持用户原图的五官、脸型和身份一致；不得以无传图的文字描述分支生成真人脸。]
不生成品牌、logo、字标、水印或签名；内页右下留出不遮挡内容的品牌安全区。
避免：[本图具体结构错误、伪字/漏字、错误姿态、物体穿插、无用装饰、冲突效果]。
本轮只处理[目标]；编辑已有图时保留[明确已通过的区域和结构]。
```

## 分模块补充

- 系列图：展开画风元素组合与布局阅读结构，保留主体/材质，删无用装饰。
- 信息图：展开数据、节点、连线、轴、图例、比例与标注对应；未提供的数量不能画成精确统计或测量。
- 封面：展开 type/palette/rendering/text/mood/font 六维，标题用冻结稿，不把全文微缩到封面。
- 真人封面：完整读 gbro-cover-design 原 SKILL、所选模板和示例，展开构图、安全区、准确标题及人脸一致性要求；实际图1只能是用户已配置的真实人脸，原图核对后作为输入，不允许凭文字生成人脸。成图对照原图实看长相；原例子中的品牌和示范文字仍按本帖准确文字及封面无品牌要求处理。
- 漫画：每格有动作、景别、人物身份、对白和顺序，每页有相同角色定义/真实参考；落实特殊预设规则。
- 角色表：各视角为同一角色，发型、衣服、配件、颜色和比例固定；角色表与发帖页分别生成检查。

中文反复出错时，可保留无品牌底图，用宿主已有排字/编辑能力放入冻结文字；无该能力就标待完成。不为过检删掉必要文字、用伪字替代或自动换供应商。修字后复查结构与事实，品牌最后叠加。
