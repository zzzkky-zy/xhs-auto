# 每批每帖选择不同的预设风格

这是用户 2026-10-16 确认的新增要求：每一批次的每个帖子都选择不同的预设风格；具体如何选择，仍按照各个原 skill 的选择方法，参考本批真实读过的爆款和要制作的内容。用户举例的 10 帖不是固定批量，数量取本批实际约定。

原帖子方法的不同主参考、完整内容、风格×布局、黑板/笔记限制和全部质量审查继续执行。原文“5 帖至少 3 种风格”不能被拿来降低这次的逐帖不同要求。原文件不改，新增要求在这里连接。

## 研究后一起选，再逐帖制作

1. 按原帖子方法研究，给每题绑定不同的主参考。先读参考的标题结构、封面构图、内页信息密度和版式节奏，再根据本题内容选择制图模块。
2. 读取所选模块的原方法、自动选择规则和完整预设定义，从现有可用预设中为每帖选择不同的预设风格。沿用原方法的内容匹配、维度选择、兼容性与参考处理，不按序号机械轮换、不抽签、不先统一模板再补参考。
3. 在本批现有计划或制作记录里列出每帖的主参考、制图模块、所选预设风格及定义文件、选择理由和内页的视觉安排。封面和内页可以用不同模块，同帖仍遵守[视觉约定](../visual-production.md)；不能只换封面名字，内页继续整批同一套皮肤。
4. 整批检查所选预设是否重复；重复时回到相应原方法，为相关帖子重新选择与其内容适配的不同预设。改颜色、标题、道具或预设名字，不能把同一个预设算成另一个。只有布局变化也不能冒充另一个画风；原方法中命名的完整风格组合按其完整定义判断，不把构图、配色、渲染等维度混为一谈。
5. 方案确定后逐张制作和实看。最后连看整批封面及各帖内页缩略图，核对实际图片仍能识别所选预设，且每帖确实有不同风格；名字不同但成图全是同一套皮肤仍不通过，按原审查流程返工对应帖子。

可从全部已接入的制图能力中选择，不只在原系列图的几种画风里选择，不要求每批把所有模块用一遍，当前账号每批必须至少一篇真人封面，按[最新内容要求](../content-requirements.md)和私人配置执行。已排除的选项仍不能选。没有足够适配的不同预设时如实保留未完成部分，不能恢复已排除选项、编造一个不存在的预设或把重复算成不同。
