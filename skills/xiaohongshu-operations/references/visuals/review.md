# 内容与视觉审查

生成前审查方案与提示词，生成后审查实际图片。每项结果给出图号、观察问题及下一步；未查看、不适用不能记成通过。没有读图能力就保留待检查，不因文件存在或尺寸正确放行。

## 生成后逐张实看

1. 内容兑现：主信息清楚，符合标题承诺与正文；未编造效果、经历、统计或把示例冒充记录。
2. 文字逐项对照：漏字、乱码、拼写、数字单位、否定和限定、对白归属。文字识别只能辅助，仍须实看。
   另查全部页脚、小字、气泡、贴纸、截图与角落：出现任何声明、解释或免责附注即不通过；模型新增文字不能因清单里没有就漏查。最终正文和待发参数也须同稿无残留。
3. 阅读与密度：手机大小下可读，标题—主体—标签有层级，箭头/分镜方向明确，不靠极小字解释。
4. 结构与功能：标注对到部位，矩阵行列一致，比较口径相同，流程不颠倒；接触、比例、支撑、视线合理，不为填满图编数据。
5. 视觉约束兑现：适用的光源/阴影、材质、透视、背景与尺度一致；平面、像素、水墨、夸张漫画按自身逻辑检查，不强加照片标准。
6. 风格和克制：仍能辨认选中风格的笔触/色块/网点/分镜；减少的是堆叠，不全退成纯文字卡。专业图解的准确不等于课件口吻。
7. 同帖一致性：连看缩略图，颜色语义、字形、材质、角色/道具可连续识别；换模块仍像同一篇。
8. 品牌：封面无品牌；内页叠加前核对原 PNG 来源，叠加后标志完整清晰、未拉伸变色、不挡内容。生成稿有伪标志先移除，不能再盖真标志蒙混。
9. 真人封面：对照实际传入的用户原图实看可见的五官、脸型与人物特征一致；不接受 AI 编造或换人的脸。背影/局部出镜按原模板检查可见范围，未露五官不记为五官已核验，真实图1仍是必需输入。检查内页仍无真人，不能把封面人物锚点传给内页生成真人。
10. 整批差异：连看各帖封面和内页缩略图，核对每帖的不同预设在成图中确实体现，不能仅记录名不同或全部内页同皮肤。失败回到相关帖子选预设/制图，不把旧“至少3种”当作本批通过标准。

## 分模块重点

| 模块 | 重点 |
| --- | --- |
| 系列图 | 每页有新信息，话术完整，画风和布局各司其职 |
| 信息图 | 节点/箭头/分类/包含/交集与来源一致，轴与单位准确，装饰刻度不冒充实测 |
| 封面 | 第一眼主题明确，准确标题未擅改，六维不冲突，价值不透支正文 |
| 真人封面 | gbro 原构图和安全区兑现，实际图1为用户配置的真实人脸，成图长相一致，封面无品牌；内页无真人 |
| 漫画 | 分格顺序、对白归属、角色外观、左右位置/道具连续与动作因果，特殊规则实际出现 |

局部错误先保存上一稿、改对应提示词，再只修本页明确问题，复查受影响项。信息有误回文字/资料；模块不适合回构图；能力欠缺或事实不明则待完成。沿用主流程最多 3 轮审查返工，不无限出图，不把失败页算完成，也不触发真实发布。

产品资料完整原文、帖子 CTA、评论福利和用户确认的真人封面数量须按[最新内容要求](../content-requirements.md)制作与逐项自审；缺话题模板的兜底只影响 tags，不影响这些业务要求。
