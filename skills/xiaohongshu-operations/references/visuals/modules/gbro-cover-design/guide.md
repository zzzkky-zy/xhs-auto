# gbro-cover-design 真人封面接入

实际制作必须完整读取 [原 SKILL](upstream/SKILL.md)，再按原步骤读取选中构图的完整模板和 [examples.md](upstream/references/examples.md)。原文、10 种模板、8 张成品示例及许可均完整保留；固定来源与逐文件哈希见 [manifest.json](manifest.json)。这里仅连接用户确认的新增要求和当前宿主，不替代、压缩或改写原制作方法。

## 用户已确认的要求

- 真人只用于封面，内页仍执行无真人规则。人物只能来自用户首次配置上传的真实人脸参考图，保持同一个人的长相；不能用 AI 编造人脸，也不能把上游成品示例里的人当成用户人物。
- 第一次业务配置先询问是否允许真人封面，保存 `cover_person_enabled` 及来源；拒绝则跳过本模块、不索要照片、不阻塞配置。允许才请上传有权使用的模特照片（不限定本人）；原件长期放包外私有素材目录，现有完整 `content_profile` 中保存 `face_reference={file,sha256,source_ref}` 和 `confirmation_sources.face_reference`。具体核对与合并保存见 [一次配置](../../../continuous-operations.md)。原 `assets/my-face.png` / `config.md` 只改连接到上述私有位置，原文件不改，不在 skill 目录新增用户照片或偏好库。
- 真人封面必须实际把该图传给生成工具作为图1。生成前实看原图、核对文件哈希和用户来源，本批准确副本沿现有来源记录绑定。无图、图不可读、哈希不符、来源未确认或工具不能接收参考图时，该真人封面待完成；原文第二轮“没有人脸图就描述人物”的分支不执行，不拿文字描述代替输入图。
- 先满足私人配置中的每批真人封面最低数量；配置要求至少一篇时先安排这一篇，再结合内容自主选择具体构图。每批每帖选择不同现有预设风格，按 [批次要求](../../batch-styles.md)结合爆款和内容、依原选择方法判断；10 帖仅为举例。原三轮的风格、标题、素材、表情、背景、字体和字色完整资料继续参与选择，用户已授权模型自主作这些制作决定，已有资料不逐封面重问。缺少真实人脸等必要材料时再请用户提供。

## 原方法实际读取顺序

1. 完整读原 SKILL，根据文章内容按第一轮原方法推荐候选风格及标题，结合本帖主参考与本批已选预设作自主选择；标题仍须兑现正文，进入 Humanizer 核对和本帖准确文字稿。原 4–8 字候选标题要求、各风格背景/字体逻辑及原核心要求照原文执行。
2. 图1固定使用已配置真实人脸；图2起按原第二轮处理本帖真实 UI 截图、产品图等已有素材，注明每图是什么、承担什么。不会因原示例展示了某个产品就补造本帖素材。示例图片用于理解原构图，不作为默认人脸输入。
3. 按原第三轮选择适用表情、背景色调、字体和字色；原文不适用项仍跳过，各风格自己的背景/字体逻辑完整执行，不统一套同一颜色字体。

## 提示词、出图和实际检查

先用 [Naturalizer](../naturalizer/guide.md)形成方案，文字由 Humanizer 核对。提示词第一行严格沿原文写“3:4 竖版构图”，发帖交付沿用 1080×1440 PNG；原安全区要求人脸、标题和主体道具距四边至少约 10%。原具体姿势、空间关系、具象隐喻、无发光特效和字体规则继续执行。准确文字在提示词中逐字列出，不复用原例子的标题或补造可见文案。

原文“只输出提示词，由用户拿去跑图”连接到当前宿主已有的图像生成/编辑能力：实际传图1及必要图2起素材，逐张生成、实看、保存，不另装供应商或增加费用。不得把未传图的描述分支用于生成人脸，也不把无法保持人脸的结果算完成。

所有图片继续执行 [对外文案规则](../../../audience-copy.md)、[统一提示词约束](../../prompt-template.md)与 [实际视觉审查](../../review.md)；内部来源与检查记录不画到图上。封面无品牌，原例子中的产品图若有品牌只用于真实材料的内容理解，不能要求模型重画 logo 或署名。内页继续按原 PNG 收尾且无真人，不能把真人封面当内页人物锚点传入。

成图必须与用户实际输入的原图对照，核对可见的五官、脸型与人物特征一致，逐字看标题、安全区、手与道具、背景/字体逻辑。背影和局部出镜仍按各原模板的露出范围检查，未露五官不能写成已核验五官，图1仍必须是真实用户参考；再连看本批各帖，确认不同预设实际兑现。原 SKILL 的中文逐字检查由 agent实看执行，不把检查工作交回用户。返工次数沿原帖流程，缺必要材料或能力则保留待完成，不调用发布。
