# 封面基础提示词规则

将所选维度的定义展开到完整提示词，不只写名字。

- 单一主视觉，标题与主体有清楚层级。hero 可占 60–70% 主体面积，minimal 可留 60% 以上空白，具体安排服从画幅与内容。
- type 决定主体/文字位置；palette 给出背景、主色与强调色的实际色值；rendering 决定线条、纹理、深度与物件词汇。
- text 决定无字、单标题、标题+副题或加 2–4 个关键词标签；准确文字来自本帖已核对并冻结的稿件。
- mood 决定视觉重量：subtle 较轻、balanced 常规、bold 较强；不以牺牲文字对比和可读性表达柔和。
- font 用所选字形定义，与渲染兼容；风格字形不得改动准确文字内容。
- 辅助元素来自内容而非装饰库存。有参考人物时按选定渲染转成示意/插画，保留已指定的发型、衣着、姿态，不借此冒充真实现场。
- Naturalizer 的用途/读者、构图/阅读路径、适用物理/功能/文化约束与具体避免项必须进入实际提示词。
- 模型不生成 logo、字标、水印或签名。封面沿用无品牌；如任务另明确要求品牌，仍只在后期放指定原素材。

完整六维定义以模块 guide 所链接文件为准；文字和线条可以有表现力，不默认全变成图标加白底大字。
