# 收敛封面选项

先展开已指定的组合，再用 auto-selection 和 compatibility 文件补齐未指定的维度。显式 palette/rendering 只覆盖对应分量，不丢失其他已选值；六维都记录为“值 + 内容理由”。

- 已有任务选择或同帖视觉约定：沿用，不重复问。
- 内容信号足够：列明 type、palette、rendering、text、mood、font、画幅及理由，继续制作。
- 存在影响承诺、事实或明显不同内容方向的歧义：把具体取舍与影响合并说明，按宿主可用的提问方式收敛；不先生成多版来代替判断。
- 用户要求选方案时，可给 2–3 个确实不同的完整组合，说明主视觉、文字分工与阅读感，不把颜色微调冒充不同方向。

小红书的 3:4、1080×1440 来自运营流程，无需每张重新设置；其他平台沿用本轮明确画幅。这里不创建 EXTEND.md、不写供应商配置或另建输出目录。
