# 单张封面提示词模板

先将已定六维、实际参考和 Naturalizer 方案填实。保存为本帖中的封面提示词文件。本文是内容模板，不是新增命令或参数。

```markdown
# 封面方案
用途/读者/第一眼信息：
正文摘要：只为提炼主视觉，不把全文画上去
准确标题：本帖已核对的最终标题
准确副题/标签：仅在所选 text 级别需要时逐项列出
画幅/语言：
六维：type / palette / rendering / text / mood / font 的确定值
各维度理由：
主视觉：来自内容的具体物体、场景或隐喻，数量和动作
构图：主体、标题和留白的位置/比例，明确阅读路径
颜色：背景、主色、强调色的实际色值及语义
渲染：线条、边缘、纹理、色块、深度、字形
适用约束：光源/阴影、材质、尺度、姿态、接触、功能与文化场景
不适用项及替代：如平面无投影，以色块关系保持层次
参考：实际图/附件标识，direct/style/palette，用途和具体保留项；无图写仅文字提取
本轮唯一目标与具体避免项：
```

## 合成实际生成提示词

```text
为[具体读者/用途]制作一张[画幅、语言]封面，表达[正文能兑现的核心信息]。
采用[构图完整描述]；主视觉是[具体对象/动作/环境]，位于[位置/面积]。
阅读顺序为[主体/标题/辅助标签的明确顺序]，保留[位置/比例]留白。
配色固定[实际色值]，渲染采用[线条、纹理、深度和物件表现规则]。
氛围以[具体对比、饱和、线重]体现，字体为[字形/字重/层级描述]。
按[准确位置]原样排入以下文字，不改写或增添：[准确标题及本次需要的副题/标签]。
[无字方案则明确无文字，不要求保留不存在的标题区。]
[实际约束：光源、材质、大小、支撑/接触、功能；平面画风写其替代规则。]
[实际传入参考及应保留的具体特征、集成位置；无传图则只写提取的特征。]
不生成品牌、logo、字标、水印、签名或随机装饰词。
避免[本图具体错误/冲突]；本轮只处理[目标]。
```

用 [共用模板](../../../../prompt-template.md) 核对字段，用 [完整参考处理](reference-images.md) 核对材料。品牌即使在参考图中可见，也不要求复现字标笔画；仅在本轮明确需要时由指定原素材后贴。封面与内页的一致性依靠约定的颜色/材质/字形/主体，不靠模型重画品牌。

生成前检查准确文字、维度兼容、参考真的可用，生成后实看标题承诺、文字与构图是否兑现。宿主不支持传图但可实看参考并完整提取特征时，可按文字方案继续，记录仅文字参考；只有出图能力缺失，或必要参考无法读取且无法补齐具体特征时才保留待完成，不虚构模型已参考。
