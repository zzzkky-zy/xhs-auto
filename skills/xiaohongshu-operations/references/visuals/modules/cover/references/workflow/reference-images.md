# 参考图处理

先区分参考用途：direct（需要延续主体/角色）、style（线条、材质与构图）、palette（颜色）。仅取相关特征，不复制他人的文案、私密资料或把参考中的产品效果当成本帖事实。

## 输入与可用性

- 本地图片：确认可读、实际查看，再记录路径；需要复制到本轮资料目录时保留来源，不动原件。
- 宿主附件/最近图片：使用宿主已提供的实际引用方式；不因没有文件路径就要求用户另传。只有生成工具确实无法访问且必须使用该图时，才请求补齐材料。
- 不能传入图：先实看并记录具体特征，提示词写这些特征，明确仅文字提取，不声称模型见过图；不能伪造 references 文件条目。

## 深读与集成

| 项目 | 提取内容 |
| --- | --- |
| 构图 | 主体/文字区位置、面积比例、留白、观看距离、裁切和阅读方向 |
| 渲染 | 线条粗细、边缘、纹理、色块、深度、笔触或格点 |
| 配色 | 背景/主色/强调色与可取得的色值，不能只写“高级配色” |
| 主体 | 数量、外观、动作、姿态、衣服/配件、相互位置及必要身份特征 |
| 字形 | 字重、大小层级、字距和排法；不沿用参考文字内容 |
| 品牌 | 识别需留位的区域和指定原素材路径；排除出模型重画指令 |
| 集成 | 哪些特征用于本页、位于哪里、如何配合本帖主题 |

提示词中的每个必要特征写成可执行指令，例如“保持上半幅主视觉、下半幅短标题，深青背景配奶油色字，线条粗细统一”；不要仅说“照参考”。使用实际图输入时也须写清提取与集成方案。

参考影响未明确维度；显式用户选择优先。参考与明确选择冲突时说明具体冲突，不自动覆盖。同帖封面用于颜色/材质锚点时，不把其稀疏排版复制到信息图内页。生成后核对指定特征是否真的出现。

## 提示词元数据（可选记录，不是新工具参数）

references 只列实际存在且可访问的材料，包含真实 path 或宿主 attachment_ref、usage、需保留的特征。路径统一按本帖资料目录解析，不从 prompts 子目录猜测相对位置。真正调用时转换成宿主接口，不直接把这些字段当成 MCP 参数。没传图就省略 references，只在正文描述特征。
