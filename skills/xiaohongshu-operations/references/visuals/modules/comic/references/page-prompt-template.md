# 漫画单页生成提示词

与共用 Naturalizer 模板一起填写，不只写风格名或“参考上一张”。每张角色表和发帖页分别生成检查。

```text
制作[图号/用途]，画幅[尺寸/比例]，语言[语言]。读者是[对象]，本页要看懂[单一目标]。
画风：[完整笔触、色块/渲染、材质与角色比例规则]。
基调：[具体颜色调整、光线和表情强度]；布局：[格数、各格位置/大小、阅读顺序]。
特殊预设：[本页需实际出现的动作/隐喻/情绪规则；未用特殊预设则省略]。
角色：[每位的发型、脸型、衣服、颜色、配件、比例、身份和本页表情]。
实际参考：[已传入角色表的标识及保持项；无传图写具体定义，不假称已传]。
逐格：
1. [格子位置/大小、景别、场景、人物左右位置、支撑/视线、动作、道具如何用]。
   对白：[说话人、准确文字、气泡顺序和尾巴指向]；旁白：[准确文字/位置]。
2. [按同样结构展开实际需要的各格]。
连续性：[上一格/上一页的衣服、手中物件、朝向、环境和动作承接]。
实际约束：[适用光源、阴影、尺度、透视、材料、接触、功能、文化/时代]。
有意抽象：[夸张表情、动势/气流或平面规则；仍须准确的关系]。
不生成品牌、logo、字标、水印或签名；内页右下预留不遮挡对白/动作的品牌安全区。
文字仅用上列准确清单，不改写或增添。避免[本图具体错误]。
本轮只解决[目标]，保留[已通过区域]。
```
