# 漫画部分制作与中断续做

上游的 storyboard-only / prompts-only / images-only / regenerate 表示下面这些阶段选择；本包没有新增同名可执行命令，不直接复制上游命令行调用。

| 当前要求或状态 | 读取与检查 | 继续制作 |
| --- | --- | --- |
| 只要分镜 | 原始资料、分析、角色定义 | 写分镜与角色文字，不生成图或 PDF |
| 只要提示词 | 分镜、角色、完整所选预设 | Naturalizer 参与方案，按页写可生成提示词，不调用生图 |
| 已有提示词、图片未完成 | 逐页核对提示词、准确文字、角色表和现有图 | 只做未完成页，已生成未检查先检查 |
| 指定页有问题 | 本页提示词、旧稿、问题和角色参考 | 先改提示词，再只修该页，保留通过页 |
| 角色表未通过 | 角色定义、各角度和错误点 | 先修参考表，不能带错批量出图 |

编号以实际本帖清单为准，不因文件冲突静默覆盖。每页保存模块/维度、准确文字、参考使用方式、上一稿、通过项和下一轮目标。状态保存复用既有任务/交付说明，不建立另一个任务库。若分镜修改影响已经通过的页，明确列出受影响页再局部重审；无影响页不重做。
