# 统一红线清单（v6.3 · 含 2026-10-14 质量补丁）

三个节点各查一遍：**选题** → **草稿(文)** → **成稿(图+文)**。  
每节点最多 **3** 轮返工；仍不过 → **换题补齐原定数量**。只记 **pass / fail**（可附一行原因）。全自动。

## 总目标红线

- [ ] 间接获客（关注/收藏/互动），非直接卖货
- [ ] 正文有具体价值，已确认的产品表达、CTA与福利完整

## 选题红线

- [ ] 面向面试/求职/应届等目标读者，有可收藏角度
- [ ] 非鸡汤空话、非无厘头、非说明书目录题
- [ ] 本批/近批不撞题
- [ ] 每题已绑定不同爆款 exemplar（本批每帖不同预设）
- [ ] 拟定标题通顺口语（不通顺直接 fail）

## 文案红线（草稿 + 成稿文字）

- [ ] 爆款结构清晰；封面文案与标题刻意错开
- [ ] 标题通顺；无别扭省略句
- [ ] 真人语气；实用/可收藏
- [ ] 干货/技巧类含完整示例 + 可收藏模版/话术；信息量够
- [ ] 正文不复述图片已有内容；正文 = 钩子 + 总结/拓展
- [ ] 无鸡汤、无说明书腔、无硬营销、无无厘头
- [ ] 无课件/催作业口吻（今晚小练习、今晚就干这些、今天就这么做、本周只改…）
- [ ] 无 AI 腔（思考过程、无意义免责、「作为AI」）
- [ ] 实际正文中CTA及福利符合私人配置，轻改保留全部意图
- [ ] 话题使用配置模板，缺失改用相关tags（不在 body 里用普通 # 文字冒充）

## 配图红线（成稿）

- [ ] ≤5 页；内页无真人；真人封面数量和真实参考照符合私人配置
- [ ] 封面可点击、有吸引力，视觉像所绑 exemplar（非简陋白底条）
- [ ] 封面无 logo；内页角落小 logo 水印
- [ ] 信息密度够：非「少字挤顶 + 大片留白」；排版层级合格
- [ ] 本帖风格与同批其他帖有可辨差异（同皮肤连发 → 本帖或整批 fail）
- [ ] 无文字截断、无混字体、无乱码/缺字、无课件式模块标题（触线 → 整图重出）
