# 研究、热门池与选题

## 目标

**服务账号当前获客目标**：触达求职/面试/应届用户，带来关注、收藏与互动，再转化。禁止把研究做成「找带货帖」或「直接卖产品」素材库。

## 默认搜词池（灵活，不锁死）

可从下列词选用（可换/可增减，但本批须覆盖其代表主题）：

- 面试
- 求职
- 应届生找工作
- 大厂岗位
- 面经
- 岗位真题
- 黑科技AI工具
- 找不到工作创业
- 求职陪跑
- 大厂内推

每个实际用到的词，优先用最多点赞/收藏/评论找候选；先近 7 天，不足再真实扩词/扩时并记录。新批次必须有本次真实搜索。

## 热门池

进池同时满足：

- 赞/藏/评任一可靠可见值严格 **>200**
- 非广告/商单
- 打开并读完全部正文与配图

**够用**：池内不同合格帖 **≥50**；主题覆盖面试求职、应届生找工作、大厂岗位、AI工具/创业/陪跑；本批约定数量的选题各有可做角度（每题必须有不同主参考/exemplar）。

## 产出本批选题

每题写清：目标读者与处境、核心意思与标题承诺、**间接获客理由**（为何带来关注/收藏而非硬广）、必需主参考。

选题前过 **选题红线**（见 redline-checklist）：鸡汤空话、说明书、硬营销、无厘头、明显无法做成可收藏干货 → 换题。

## 质量补丁：Exemplar 多样性（2026-10-14）

- 热门池不仅用来选题角度，更要为每帖选定 **可抄的视觉+结构 exemplar**。
- 本批每帖选择不同的现有预设风格；禁止研究阶段就预定「统一卡片模版出图」。
- README/批次记录须写明每帖 exemplar 与抄了什么（封面构图 / 内页信息密度 / 话术呈现方式）。
- 若本批各帖只能落在同一种简陋版式，视为研究失败，重做热门池浏览后再选题。
