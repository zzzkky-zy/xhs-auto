# 文案、配图与制作

## 文案

- 跟**所绑爆款 exemplar** 的结构（钩子 → 共鸣/痛点 → 干货分层 → 收束），不要同批各帖共用同一套提纲腔。
- 封面文案与标题**刻意错开**（封面抓点击，标题补信息差）。
- **标题必须通顺**：像真人会搜、会点的口语句；禁止别扭省略（例：用「面试时别太老实，应该这么说」而非「面试时别太老实怎么说」；用「秋招别在这三件事上浪费时间」而非「秋招别浪费时间的3事」）。
- 真人语气；实用、可收藏优先；非鸡汤、非说明书。
- **干货/技巧类硬性要求**：至少一组完整示例 + 可直接收藏的回答模版/话术（场景、示范回答、要点）。信息量不足 = 草稿 fail。
- **正文 vs 图片**：正文**禁止**复述图片上已有句子；正文 = 钩子 + 总结或拓展。干货本体放在图里。
- **禁止课件/催作业口吻**：无「今晚小练习」、无「今晚就干这些 / 今天就这么做 / 本周只改…」。
- 正文重点是本题的实用内容；按私人配置保留已确认的产品介绍与文末CTA。
- CTA取私人配置或保持完整意图的轻改；话题模板找不到时用最相关tags。
- 触红线本地改：鸡汤、说明书、硬营销、无厘头、AI腔、催作业、标题不通顺、正文抄图。

CTA全文、福利和品牌来源读取当前私人配置；不得凭历史样例替代。

## 配图（强制结合 sweety-xhs-images）

出图前必读：[系列图方法](../../../visuals/xhs-series.md)及其完整预设、布局和工作流。

### 风格 × 布局（每帖一对，同批各帖不雷同）

| 维度 | 选项 |
|------|------|
| 风格 | cute / fresh / warm / notion / chalkboard / study-notes / screen-print |
| 布局 | sparse / balanced / dense / list / comparison / flow / mindmap / quadrant |

求职面试干货默认推荐（**去课件感**）：

| 内容类型 | 推荐风格 | 推荐布局 | 备注 |
|----------|----------|----------|------|
| 避坑/反问清单 | notion | list | 高冲击，非白板 |
| 模版/可套话术 | cute 或 notion | list / dense | 贴纸块，非 PPT 模块 |
| 翻车 vs 加分 | notion | comparison | 左右强对比 |
| 对话气泡话术 | warm | balanced | 卡通气泡，暖色 |
| 大字钩子+公式 | fresh 或 cute | sparse→flow | 封面 sparse，内页 flow |

**慎用** `chalkboard`、`study-notes` 作为主风格（易变课件/笔记纸）；确要用须明显卡通化且整批不超过 1 帖。

### 硬视觉规则

- **抄 exemplar 视觉节奏**，同时用 sweety 风格渲染；封面要有吸引力。
- 本批每帖须采用不同的现有预设（layout 也可不同）。
- 真人仅用于封面，按私人配置的最低数量，实际传入参考照；内页无真人；**≤5 页**；默认 1080×1440（3:4）PNG。
- **封面不贴 logo**；内页角落小 logo 水印（浅底墨色/深底白色，约 180–240px，右下边距 ≥48px）。
- **信息密度**：内容铺满可用画幅，禁止少字挤顶大片留白。
- **封面禁止「xxxx · xxxx」眉题**（顶栏双段小标题用 `·` 拼接）：不要「反问环节 · 可直接收藏」这类；封面只留主钩子标题+内容区。
- **禁止课件皮**：白板分区标题条、教材章节感、灰底堆叠模块、作业练习页观感。
- 目标观感：**卡通信息图**（手绘/贴纸/色块/装饰），像小红书高赞图。
- 系列一致性：先出封面作视觉锚，后续页可用封面作参考图。
- 视觉红线（截断、混字体、乱码/缺字、课件模块标题）→ **整张图重生成**。

品牌原素材见 [原PNG与校验信息](../../../../assets/brand/manifest.json)，禁止生成或手绘替代。

## 草稿与成稿

完整草稿须含：标题、正文、各页拟用文字/画面、**绑定的 exemplar 笔记 id/链接与抄了它哪一点（结构或视觉）**、**本帖 sweety style×layout**。

草稿红线通过后再出图；成稿红线（文+图+风格多样性+非课件）通过后才进 MCP 发布。
