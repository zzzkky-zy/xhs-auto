# 流程与自审

热门池研究 → 选题检查 → 完整初稿 → Humanizer编辑稿 → 逐图生成与实看 → 成稿与业务要求复核 → 在本次授权范围内发布。

三个节点均按 [红线清单](../assets/handoffs/redline-checklist.md) 实际审读；每节点最多3轮返工，失败换题补足原定数量，不降低批次目标。结果未知或可能发送的内容不得换编号重发。

程序验证字段、文件哈希、材料与最终发送参数一致；语言、信息量、人脸相似度和视觉质量由agent审读实看。每项结论提供实际文案摘录或图像观察，不能只勾选通过。阶段登记与实际工具参数见 [内容审查](../../../../../../docs/CONTENT-REVIEW.md)。

数量、排期、批准和接续按当前配置与实际用户指令；已有无需审核的发布授权可直接自审执行，不再重复审批。
