# 图文研究、制作与质量要求

## 执行顺序

1. 完整读 [研究方法](references/research-and-readme.md)，热门池至少50篇，赞藏评任一项严格超过200；每题绑定不同主参考。数量按本次任务。
2. 读 [制作方法](references/post-production.md) 和下列完整质量要求。正文、图字分工；采用私人配置的完整CTA与福利，允许意思不变的自然改写。
3. 使用 [视觉入口](../../visual-production.md)，逐张制作、实看；每批每帖不同预设，真人最低数量取当前私人配置，使用真实参考照。
4. 选题、草稿、成稿逐项检查 [红线清单](assets/handoffs/redline-checklist.md)，并按 [流程检查](references/workflow-checks.md) 保存真实阶段及证据。
5. 发布只用当前 [运行规则](../../../../../docs/RUNTIME.md) 与 [MCP字段](../../../../../docs/MCP-CONTRACT.md)，按已有授权执行。

## 完整质量要求


### A. 抄爆款，不自创「安全简陋风」

- 封面与内页的**视觉表达形式**以热门池 exemplar 为准：构图、对比、留白、字号层级、色块/贴纸/列表样式直接模仿高赞帖。
- **禁止**自造毫无吸引力的极简白底小字条；若做出来不像任一 exemplar，成稿红线 **fail**。
- 本批每篇必须选择不同的现有预设风格（例如：大字封面钩子型、分镜对比型、密集清单型、对话气泡话术型等）。同批各帖皮肤一模一样 = **整批 fail**，根因视为未真正分 exemplar 参考。

### A2. 配图必须结合 sweety-xhs-images

出图前必读本地 skill：[系列图方法](../../visuals/xhs-series.md)（来源 [threerocks/sweety-skills](https://github.com/threerocks/sweety-skills)）。

- 每帖选定一对 **风格 × 布局**（同批各帖之间风格不得雷同；本批推荐避开纯课件感：少用/慎用 `chalkboard`、`study-notes` 作为主风格）。
- 推荐映射（可按内容微调）：干货清单 → `notion`+`list` / `notion`+`dense`；对比翻车 → `notion`+`comparison`；对话话术 → `warm`+`balanced`；大字钩子封面 → `fresh`/`cute`+`sparse`；模版贴纸 → `cute`+`list`。
- 视觉目标：**卡通信息图**（手绘感、贴纸、色块、装饰），像小红书高赞种草/干货图，**不是** PPT 课件、白板模块条、作业练习页。
- 封面优先 `sparse` 大钩子；内页再用 `dense`/`list`/`comparison`/`flow` 铺信息；系列内用参考图链保持风格一致。
- 详规写在 `references/post-production.md`。

### B. 信息量与排版

- 图文合计信息量要够收藏：干货/技巧类必须含 **完整示例 + 可直接收藏的回答模版/话术**（场景→怎么说→为什么这样说）。
- 图片内容禁止「很少字挤在上方小空间、下部大片空白」；信息应合理铺满可用画幅（仍可读、不截断）。
- 图片制作须达到可发水准：层级清晰、对齐、对比足够；简陋线框堆字 = fail，整图重出。

### C. 正文 vs 图片分工

- **正文不得复述图片已有原文**；正文只做：钩子 + 总结或拓展（补一张图没写清的动机/边界/怎么用）。
- 图片承担可收藏干货本体；正文短、狠、有信息差。

### D. 标题通顺

- 标题必须是通顺口语中文，读得顺、像真人会搜的句子。
- 坏例：`面试时别太老实怎么说`；好例：`面试时别太老实，应该这么说`。
- 坏例：`秋招别浪费时间的3事`；好例：`秋招别在这三件事上浪费时间`。
- 选题/草稿红线检查标题通顺；不通顺 = fail。

### E. 禁止课件/催作业口吻

图片与正文均禁止：

- 「今晚小练习」「课堂练习」等课件式标题/模块
- 「今晚就干这些」「今天就这么做」「本周只改…」等催作业收束
- 白板分区标题条、教材章节感排版、灰底模块堆叠的「课件皮」

改成可收藏的清单、模版、对照表、可复用话术，让用户自己决定何时用；视觉走卡通信息图。

### F. 封面禁「xxxx · xxxx」眉题

- **封面顶部禁止**「分类 · 卖点」式双段眉题/副标，例如：`反问环节 · 可直接收藏`、`压力面 · 被打断怎么办`、`高频雷题 · 话术气泡`、`1分钟自我介绍 · 可直接套`、`面试口述 · 无对口经验`。
- 判定：封面最上方出现用间隔号 `·`（或同类分隔）拼成的两段小标题 = **fail**，须重出封面。
- 封面只保留：**主标题钩子**（可加大字）+ 正文信息区；需要场景说明时并进主标题或列表项，不要单独顶栏眉题。
- 内页页码/分区若必须标注，避免「1/3 · 模版」这类顶栏双段眉；可用纯数字页码或直接进入内容。
- 本条写入制图硬规范，以后每一批封面成稿红线检查。
