# 评论与回评方法

先读原帖与评论，针对具体细节提供帮助，再按当前私人配置自然介绍产品。完整产品原文、笔风、福利和示范句从私有content_profile及product_materials读取，不能概括成一两项卖点，也不限制每条只能讲一个能力。

## 策略

A为纯帮助，不提产品；B为具体帮助加自然产品介绍；C仅用于对方明确求工具、资料或推荐的场景。比例与C的许可取当前配置；目标条数取本次约定，不设置固定30条。推广评论保留已确认的产品定位、相关能力组合和福利邀请，允许完整介绍和自然改写。不能为避免营销腔而删除已确认内容。

## 选帖规则


入选必须同时满足：

1. **主题对口**（与人设/卖点相关）
2. **近一周内**发布（超一周跳过）
3. **评论数 ≥ 5**（已有讨论热度；评论过少的帖一律不选）
4. **互动适中**：有人看且评论区未刷到完全埋没；仍避开**万赞级且评论上千**的超级爆款（评论区已被淹没、露出极差）

跳过：无关帖、已删/不可见、明显广告/站外导流帖、近 3 天评过的同一作者（若有去重记录）、纯引战无转化价值的帖、**敌意炒作 AI 提词/作弊**类帖、**白嫖/维权撕逼**类帖、评论不足 5、超一周、超爆款。

## 文案符号与表情

- **禁止**使用直角引号「」；可用符号仅限：，。！？、；以及必要的括号/冒号等极常用标点。需要引用原帖说法时，用自己的话复述，或改用双引号以外的自然转述（优先复述，少用引号）。
- 可适当用表情，**每条评论最多 1 个**表情；不用就不用，禁止堆表情。

## 笔风与完整示例

像真人手机打的，直接回应具体问题，允许有态度的口语；不要机械模板。例子学习表达方法，产品示范全文另读私人资料。


- A 例：确实，大厂基本都是同款压力面。给大家一个小 tips：被打断时先停一下，把对方问题换个方式复述一遍，确认问题的同时也给自己一些思考时间，比硬把自己的项目念完更稳。平时也可以专门练被刁难追问，练到肌肉反应，现场就不容易崩。
- A 例：人间清醒，至少谈吐和项目讲述是能练的。比如把每个项目压成痛点、动作、结果、踩坑四句，面试官一打断也能从最近一句接着讲，比临场编顺很多。
- A 例：太牛逼了恭喜。找工作是这样的，履历更亮也不等于更贴这个坑。半小时出结果多半是匹配和沟通都顺了。其实面试就是能把岗位最关心的两三个点讲透，比全程追求完美发挥管用。

每条点出原帖或评论的具体细节，干货可执行；不同目标改变回应与表达，不复制同句，不缩成三条口号。

## 工作流

1. 从完整业务资料拆2–3个痛点，准备直接需求词、痛点词、场景词及适用竞品词；候选约为本批目标的2–3倍，已有合格资料可复用。
2. 打开笔记，读完正文、配图要点及评论区；区分主帖与目标评论，保存准确id、链接和读取时间。
3. 按相关性、发布时间、评论数、讨论空间与具体需求筛选，记录选择理由。
4. 每条记录A/B/C、主帖或回评、原帖要点、切入点、完整草稿及理由。具体细节 → 可执行帮助或共鸣 → B/C自然产品介绍和已确认福利。
5. 完成source/draft/edited/final实际阶段和业务复核；需用户审核的任务展示原帖链接、完整评论和回评目标。已有明确免审授权或已验收持续运营范围内，直接内部自审，不重复请示。
6. **先评主帖，再挑该主帖下合适评论回评**；串行执行，间隔、故障和未知结果按 [运行规则](../../../../../docs/RUNTIME.md)。未发送的不合适目标及时更换补足原定数量，可能已发送的不能重发。
7. 保存回执与去重记录；汇报搜词、主评/回评数、A/B/C、成功/失败/未知、总耗时与改进。
