# 第二轮：减少重复工作，而不是省略必要检查

本轮已加入三类通用能力：对读过内容给出具体补读范围；对确属插件且已结束的页面提供一次性安全清理流程；执行前解释本次规则来源并指出冲突。不是修改账号运营额度，也没有恢复真实账号任务。

## 实现与使用点

- `cloud_read_reuse.py`：只读建议，保留原阅读时间，不将缓存当作新阅读。正文、图和相关评论分别判断；回复对象作者与笔记作者分开。不能生成Send许可，原120秒检查仍须执行。同状态目录的既有共享预算保持不变；不同目录不宣称全局共享。
- `cloud_owned_pages.py`：真实页面实例归属、终态证据、空编辑器、新鲜清单、暂停及限制检查；许可在返回前一次消费，未知关闭不再发。Host读取真实pacing账本及本operation全部历史attempt，避免旧未知状态被新尝试掩盖。只有确证独立且已结束、无限制的纯读故障才不拖住无关收尾。模块不直接操作浏览器。
- `effective_rules.py`：固定批次profile及来源的只读解释。区分legacy/future预约路径；浏览器内部动作时间不覆盖读/搜/发预算；C为上限而不是必须凑齐；确认引用不等于权限；真实持久暂停由Host另行回读，不接受调用者伪称未暂停。
- Host新增8个helper，skill明确实际使用点。缺旧证据仅要求必要补读，不强制重建所有历史。运行包递归收录模块和文档，并有包完整性断言。

## 验证

独立审查推动修正缺图片证据异常、回复对象作者遗漏、布尔/数字混淆、非文本确认出处、旧attempt未知绕过以及过宽全局故障拦截。模块与host相关独立检查通过。

最终整套Python检查共852项：851通过，1项跳过，0失败，57.254秒。跳过项为非macOS环境的应用身份检查；这不是Mac安装验收。全部2574个源文件、测试、文档和两份native程序的前后SHA一致。native程序仍为已在第一轮验证的linux-amd64构建，SHA256 `e6f764052f8d2d0bbd2ac129a60456718cc72ac162f7d8dd244587523802e47b`；本轮未更改Go源码。
